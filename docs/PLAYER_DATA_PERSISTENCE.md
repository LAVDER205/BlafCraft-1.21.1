# Проверка сохранения данных игрока

В этом изменении сохраняются текущая мана, её максимум и регенерация, список друзей и выбранный облик. Эти данные также переносятся при возрождении после смерти. Сами временные эффекты продолжают подчиняться правилам Minecraft; сохранённый облик не включает эффект превращения автоматически.

Ранее эти данные не записывались, поэтому восстановить уже потерянные значения невозможно. Для игрока без новых данных мана начинается с прежних значений по умолчанию.

Кулдауны остаются временными и сбрасываются при выходе, как было явно предусмотрено кодом. Назначение способностей по нику не меняется. Полёт, активные эффекты и запланированные атаки не превращены в постоянные настройки.

Автоматическая проверка `./gradlew verifyManaPersistence` записывает и читает с диска NBT маны: начальные значения, нестандартные максимум/регенерацию и пустую ману. Она входит в `check`/`build`. Это проверка формата данных, а не полный запуск игрового сервера.

## Проверка в игре на копии мира
1. Потратить ману, отметить её значение, выйти и полностью закрыть Minecraft. После запуска открыть тот же мир. Учесть, что после входа мана снова восстанавливается со скоростью регенерации.
2. Повторить для другого мира: значения не должны переноситься между мирами.
3. Проверить смерть и возрождение: мана/максимум/регенерация сохраняются, интерфейс показывает правильный максимум.
4. С двумя игроками добавить друга, перезапустить сервер и проверить, что друг остался; повторить после смерти.
5. Получить облик под эффектом превращения, выйти и войти до окончания эффекта. Модель должна восстановиться. После выхода из этого мира в другой не должен попадать облик прежнего персонажа.
6. На отдельном сервере проверить вход, смену измерения, смерть и повторный вход. Полная ручная проверка этих сценариев пока не выполнена.

Ресурсы игрока сохраняются штатным механизмом attachments в playerdata мира. Менять формат сетевых пакетов не потребовалось.
